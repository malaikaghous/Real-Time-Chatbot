
# 💬 Real-Time Chat Interface

A responsive and interactive **Real-Time Chat Interface** built using **HTML, CSS, and JavaScript**.

This project allows users to send messages instantly, stores chat history using **localStorage**, and includes a simple chatbot that responds to common predefined messages.

---

## 🚀 Features

✅ Send messages instantly
✅ Messages appear dynamically in the chatbox
✅ Different styles for sent and received messages
✅ Chat history is saved using **localStorage**
✅ Messages remain available after page refresh
✅ Smooth scrolling to the latest message
✅ UI animations for messages
✅ Timestamps for every message
✅ Press **Enter** to send messages
✅ Simple predefined chatbot responses
✅ Clear chat functionality
✅ Responsive design for desktop and mobile devices

---

## 🛠️ Technologies Used

* **HTML5** – Structure of the chat application
* **CSS3** – Styling, responsiveness, and animations
* **JavaScript** – Chat functionality and DOM manipulation
* **localStorage** – Saving chat history in the browser
---

## 💡 How It Works

1. The user types a message in the input field.
2. The message appears instantly in the chatbox.
3. The message is saved in **localStorage**.
4. A simple chatbot analyzes common keywords.
5. The chatbot sends a predefined response.
6. Both messages include timestamps.
7. Chat history remains available even after refreshing the page.

* Thank you

* Good night

* Study
